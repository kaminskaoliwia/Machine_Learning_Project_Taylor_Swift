# Machine Learning Project
In this project I created two models - **KNN** and a **Neural Network** that predicts 
whether a Taylor Swift's song is part of an "old Taylor" era or a "new Taylor" era. While some
people consider the beginning of the new era to be *Lover* I decided to include *reputation*
as the first new album, due to the famous line. After creating the models I tested all the "From 
The Vault" songs to see whether they fit more into the new or the old era.
